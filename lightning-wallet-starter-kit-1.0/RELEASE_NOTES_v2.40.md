# Lightning Wallet v2.40.0

## 本次变更

- 统一 API 能力清单、客户端诊断、页面版本显示与验收脚本为 `2.40.0`。
- 钱包签名模块复用已连接的客户端钱包会话，并在执行前重新校验账户和网络。
- 修正 EVM 地址规范化与跨链聚合路线去重，市场持仓数据可使用 GoPlus 公共数据源并明确披露来源。
- 新增 Aave V3 Sepolia 闪电贷预检与发布验收脚本；预检只构造并模拟调用，不自动签名或广播。

## 上线边界

- 所有真实签名和交易广播仍必须由用户在自己的钱包中确认，服务端不保管私钥、助记词或代签交易。
- 未配置的 WalletConnect、GasFree、自动化交付或闪电贷接收器等外部提供商仍会使相应功能保持关闭；缺少这些配置不代表已具备内测或公测就绪状态。
- Aave V3 闪电贷主网执行保持关闭，只有经过审核并部署、加入允许列表的接收器合约才能进入后续钱包验收。
